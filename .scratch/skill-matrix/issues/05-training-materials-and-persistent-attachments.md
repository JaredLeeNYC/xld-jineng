# 05 — 管理培训资料与持久化附件

**What to build:** HR 可以上传常用培训文件或配置外部链接，员工在有权限时可以安全查看或下载；附件在发布切换后仍然存在，并能独立备份与恢复。

**Blocked by:** 02 — 实现五角色工号登录

**Status:** claimed

- [ ] HR 可以创建、分类、检索、编辑和停用培训资料，并关联一个或多个技能项。
- [ ] 支持受控的 PDF、Word、PPT、图片上传及外部视频/网页链接，不实现视频转码。
- [ ] 数据库只保存附件元数据、校验值和业务关联，不保存文件二进制或主机绝对路径。
- [ ] 对象存储适配器同时支持测试用存储和一期持久化挂载目录，业务模块不依赖具体存储实现。
- [ ] 下载前执行角色和业务授权；停用资料不能用于新培训，但历史培训仍可读取原有关联。
- [ ] 文件名不能决定存储键，路径穿越、危险类型和超限文件被拒绝。
- [ ] 上传失败不会产生可见资料或悬空业务关联，孤儿对象有可验证清理策略。
- [ ] 持久化目录位于发布目录之外，备份和恢复读回步骤得到自动或脚本化验证。
- [ ] 桌面管理列表与员工手机资料视图均有 loading、error、empty 和下载失败反馈。
- [ ] 自动测试覆盖上传、授权下载、停用、校验失败、适配器错误和恢复读回。
