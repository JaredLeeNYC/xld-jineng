# 02 — 实现五角色工号登录

**What to build:** 员工和管理人员可以使用工号与密码安全登录，在手机或电脑看到符合固定角色的导航；系统在服务端阻止未登录、角色越权和无权写入。

**Blocked by:** 01 — 建立可运行的云端工程骨架

**Status:** claimed

- [ ] 支持员工、部门主管、HR/培训管理员、高层查看者和系统管理员五类固定角色。
- [ ] 使用唯一工号登录，密码以安全加盐哈希保存，session token 仅保存 hash 并通过安全 Cookie 传递。
- [ ] 初始账号首次登录必须改密，完成改密前不能进入业务页面。
- [ ] 连续登录失败触发临时锁定，错误响应不泄露账号是否存在。
- [ ] 系统管理员可以重置密码，重置后旧会话立即失效。
- [ ] 前端隐藏无权导航，服务端仍独立执行动作权限校验。
- [ ] 员工只能访问本人空间，高层页面只读；无权请求返回结构化拒绝并记录安全事件。
- [ ] 桌面与手机登录、改密、锁定提示和退出流程均可独立演示。
- [ ] HTTP 集成测试覆盖成功登录、错误凭证、首次改密、锁定、会话失效和五角色越权。
