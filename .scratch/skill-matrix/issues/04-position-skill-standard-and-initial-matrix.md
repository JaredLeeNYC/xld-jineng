# 04 — 定义岗位技能标准并展示初始矩阵

**What to build:** HR 可以定义技能项和岗位要求、导入有来源的员工初始技能；员工能看见个人岗位差距，主管能通过热力矩阵看见本部门谁达标、谁未评定。

**Blocked by:** 03 — 管理组织人员与 Excel 导入

**Status:** resolved

- [x] 技能类别固定为通用、专业、核心，能力等级固定为 0-4 并展示统一业务含义。
- [x] HR 可以创建、编辑、筛选和停用技能项，并配置是否复评及默认有效月数。
- [x] HR 可以为岗位设置技能、要求等级和是否必备，同一岗位技能只有一条当前有效要求。
- [x] 支持复制一个岗位的技能要求并批量调整，所有变更留痕。
- [x] 支持预检并导入员工初始技能；每条初始技能生成可追溯的已归档基线评定，不允许直接写无来源的当前技能。
- [x] 员工个人技能页展示岗位要求、当前有效等级、有效期和技能差距。
- [x] 主管矩阵按部门、岗位、员工和技能筛选，桌面显示热力表，手机提供可读卡片或明细。
- [x] 当前有效等级大于等于岗位要求时达标；未评定、过期或作废均不达标。
- [x] 员工当前技能始终指向通过、已归档且未作废的评定来源。
- [x] API、矩阵查询和纯计算测试覆盖等级边界、必备要求、未评定与初始导入。
