# 07 — 完成技能评定并更新矩阵

**What to build:** 评定人录入线下考核结果，部门主管确认，HR 归档；通过归档后员工当前技能和矩阵自动更新，不通过、退回、作废和复评都有清晰记录。

**Blocked by:** 04 — 定义岗位技能标准并展示初始矩阵；06 — 完成培训计划与双确认

**Status:** ready-for-agent

- [ ] 评定支持线下笔试、实操和综合评审方式，记录技能、等级、结论、证据、原因和整改建议。
- [ ] 流程固定为草稿、待主管确认、待 HR 归档、已归档、已退回和已作废。
- [ ] 主管只能确认本部门评定；HR 只能归档已经主管确认的评定。
- [ ] 主管或 HR 退回必须填写原因，评定人修订后可以重新提交。
- [ ] 归档后记录不可直接编辑；纠错通过作废原记录并创建新评定完成。
- [ ] 不通过评定可以归档但不产生或提升员工当前技能。
- [ ] 只有通过、已归档、未作废的评定事务性更新员工当前技能，并保留来源指针。
- [ ] 需要复评的技能按评定日期和有效月数计算到期日，复评归档后替换当前快照但保留历史。
- [ ] 归档后员工个人档案、岗位差距和主管矩阵在同一事务结果基础上更新。
- [ ] HTTP 集成和浏览器验收覆盖完整三级确认、退回、失败归档、作废、复评和并发重复归档。
