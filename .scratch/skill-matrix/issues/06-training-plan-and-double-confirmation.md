# 06 — 完成培训计划与双确认

**What to build:** 主管或 HR 可以发布培训并分配到人；员工查看资料后提交完成，负责人确认或退回，集中培训可批量确认，只有确认完成才形成正式培训履历。

**Blocked by:** 03 — 管理组织人员与 Excel 导入；05 — 管理培训资料与持久化附件

**Status:** claimed

- [ ] 培训计划支持草稿、已发布、进行中、已完成和已取消状态，非法状态跳转被拒绝。
- [ ] 计划可以绑定资料、负责人、时间、地点及部门、岗位或指定员工范围。
- [ ] 发布时事务性固化对象范围并为每名员工生成唯一培训任务。
- [ ] 员工在手机端查看资料并提交本人任务，提交后仍不计入正式培训履历。
- [ ] 培训负责人或员工所属部门主管可以确认或退回；退回必须填写原因。
- [ ] 集中培训支持上传签到表或照片，并批量确认实际参训员工。
- [ ] 只有已确认且未取消任务进入正式履历和完成率分子，培训完成不自动授予技能。
- [ ] 逾期根据截止时间计算，不覆盖任务生命周期；取消记录保留并不进入统计分母。
- [ ] 员工、主管和 HR 分别看到与职责相符的任务、待办、历史和证据。
- [ ] HTTP 集成和浏览器验收覆盖发布、员工提交、退回重提、批量确认、取消和越权。
