# 09 — 交付 Dashboard、指标与一致 Excel 导出

**What to build:** 主管、HR 和高层可以通过四类统一指标和技能矩阵下钻了解能力风险，并将当前筛选结果导出为口径一致的 Excel。

**Blocked by:** 06 — 完成培训计划与双确认；07 — 完成技能评定并更新矩阵

**Status:** resolved

- [x] Dashboard 展示岗位技能达标率、部门技能覆盖率、培训任务完成率和到期数量。
- [x] 指标严格使用规格定义的分子、分母、取消排除和有效技能规则。
- [x] 支持从全厂到部门、岗位、员工和技能项逐级下钻。
- [x] 技能矩阵支持部门、岗位、员工、技能、达标和有效期筛选。
- [x] 高层查看者可以只读查看全厂 Dashboard、矩阵、下钻和导出。
- [x] 主管只看到本部门指标和明细，员工不获得管理报表权限。
- [x] Excel 导出复用页面同一筛选、排序和指标计算逻辑，并包含生成时间与口径说明。
- [x] 桌面使用表格/热力视图，手机使用可读卡片或明细，均提供 loading、error 和 empty 状态。
- [x] 指标纯计算测试覆盖未评定、非必备、已过期、已作废、取消任务和空分母。
- [x] HTTP 与浏览器验收证明页面、下钻和 Excel 对同一数据集给出一致结果。
