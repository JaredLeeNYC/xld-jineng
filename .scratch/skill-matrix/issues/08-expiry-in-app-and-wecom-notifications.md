# 08 — 处理有效期、站内通知与企业微信群提醒

**What to build:** 员工和管理人员能及时看到培训、评定和技能到期消息；管理群通过企业微信机器人收到重要提醒，外部发送失败可追踪和重试且不破坏核心业务。

**Blocked by:** 07 — 完成技能评定并更新矩阵

**Status:** ready-for-agent

- [ ] 当前技能状态统一计算为有效、30 天内即将到期、已过期或已作废。
- [ ] 已过期和已作废技能保留历史，但不再计入岗位达标与覆盖。
- [ ] 培训发布、任务退回、评定结果和个人到期消息产生对应站内通知。
- [ ] 管理群事件覆盖新培训、培训逾期、技能即将到期、已过期和待确认事项。
- [ ] 系统管理员可以配置、停用和测试一个或多个企业微信 Webhook。
- [ ] Webhook 地址执行安全 HTTPS 外发校验，凭证和完整地址不进入普通日志。
- [ ] 通知事件先写持久化 outbox，业务事务成功不依赖外部 Webhook 成功。
- [ ] 每个业务事件与目标渠道具有幂等标识，失败可人工重试且不会重复业务动作。
- [ ] 发送记录展示成功、失败原因、尝试次数和最近尝试时间。
- [ ] 自动测试覆盖到期边界、定时扫描去重、网络失败、非零错误码、重试和业务不回滚。
