# 03 — 管理组织人员与 Excel 导入

**What to build:** HR 可以维护部门、岗位和员工，通过 Excel 预检并批量导入至少 50 名员工；主管只能查看本部门人员，员工能在个人资料看到当前岗位，历史岗位变更可追溯。

**Blocked by:** 02 — 实现五角色工号登录

**Status:** ready-for-agent

- [ ] HR 可以创建、编辑、筛选和停用部门、岗位与员工，历史引用不因停用消失。
- [ ] 工号、部门编码和岗位编码作为稳定业务键并具有明确唯一约束。
- [ ] 一个员工同一时刻只有一条当前有效岗位任职记录，岗位变更保留起止时间和原因。
- [ ] Excel 导入先 dry-run，逐行返回缺失字段、重复工号、无效部门和无效岗位等错误。
- [ ] 用户确认后才执行事务性导入；错误批次不会留下半成功数据或重复账号。
- [ ] 导入新员工时生成待首次改密账号，初始凭证交付不进入日志或导出文件。
- [ ] HR 可按当前筛选导出组织人员数据。
- [ ] 主管查询被强制限制在本部门，员工只能查看本人基本信息和岗位履历。
- [ ] 关键新增、修改、岗位变更、停用和导出行为产生可追溯审计事件。
- [ ] 使用 50 名员工样例完成导入、错误修正、重新预检和正式写入的自动验收。
