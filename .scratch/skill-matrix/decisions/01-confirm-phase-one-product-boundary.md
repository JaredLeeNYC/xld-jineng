# 确定技能矩阵系统一期产品边界

Type: grilling
Status: resolved
Blocked by:

## Question

在满足工厂管理需求的前提下，一期必须形成什么闭环，哪些复杂能力应延期？

## Answer

一期服务于单工厂，提供员工、部门主管、HR/培训管理员、高层查看者和系统管理员五类固定角色。员工使用响应式 Web 独立登录，查看个人技能档案和培训任务、打开材料并提交完成；培训负责人或主管二次确认后形成正式培训履历。

技能评定采用“评定人录入 -> 部门主管确认 -> HR 归档生效”的固定流程。技能类别固定为通用、专业、核心，能力等级固定为 0-4；岗位要求等级与员工当前有效等级形成技能差距。技能项可选择有效期，到期技能不计入当前达标率。

一期提供员工和组织 Excel 导入、轻量资料库、技能矩阵、四类核心指标、Excel 导出、站内通知与企业微信群 Webhook。Webhook 用于管理群提醒，员工个人消息使用站内通知。在线考试、扫码签到、APP、小程序、复杂审批、自定义分析和外部系统直连延期到二期评估。

上线基线为至少 50 名员工、3 个岗位，完成一次培训到矩阵更新的真实闭环，五类角色可用，企业微信通知可达，连续试运行一周无阻塞问题。
