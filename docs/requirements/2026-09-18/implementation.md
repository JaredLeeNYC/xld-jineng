## 本轮业务解释

- 领导审批复用HR和部门主管，按原授权部门限制；计划提交人不得审批本人计划。
- 负责人只能为有效主管或HR，员工端严格只读。
- 实际开始时间允许早于计划时间，实际与计划分别显示，不以定时状态替代实际开始记录。
- 培训考核成绩为0至100分，可含两位小数；合格结论由录入人独立选择，不按未经指定的及格线自动推断。
- 新技能评定按最新流程保存即待HR归档，证据及说明可选；归档仍须独立复核。旧待主管确认记录继续兼容。
- 同名邓华明管理账号须唯一且有效，发布脚本授予全厂只读，保持原角色及写入部门范围；不创建或启用账号。
- 岗位所属部门改变前须先调整其当前任职关系，避免编辑岗位导致员工被静默调动。
- 删除采用停用或逻辑移除，明确保留历史；旧培训外链继续可读。

## 验收门禁

公开service行为测试、真实HTTP和隔离PostgreSQL合同、前端桌面/手机交互分别核验。独立验收失败写入测试报告返回原开发者；复测原步骤并回归关联流程，不使用开发自测替代独立结论。

最终要求 bun test 与 bun run check 全通过；考核专用真实DB验收脚本全部通过；所有需求追踪项关闭、独立报告无待修缺陷后才push main。main推送会触发测试环境自动部署，需核对工作流、提交SHA、health/ready和只读授权执行标识。
