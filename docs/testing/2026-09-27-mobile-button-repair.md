# 2026-09-27 手机端操作按钮修复

独立验收发现：390px 手机界面中，技能标准、培训管理等页面的纯文字主按钮变为绿色小点或空白条，影响保存操作识别。问题已回流主智能体修复。

## 复现证据

验收智能体运行独立 Playwright 浏览器与本轮合成测试账号，保存 `2026-09-27-mobile-buttons-evidence.json` 和手机截图。培训管理「保存资料」按钮无图标，计算样式 `fontSize=0px`；技能标准「保存岗位要求」等按钮也不可辨认。

复现命令：工作区依赖 Node 运行 `.tmp/qa-button-red-20260927.cjs`。同脚本用于修复后读回计算样式。脚本仅连接 localhost 的隔离验收环境。

## 根因与修复

公共手机媒体查询对所有 `.primary-button` 设置 `font-size: 0`，连没有图标的业务按钮也隐藏了。恢复主按钮及面板标题操作按钮的正常 13px 字号，保留手机间距。未修改业务权限或保存逻辑。
