## 缺陷闭环与边界

独立浏览器验收发现 QA-01：手机纯文字主按钮因公共 `font-size:0` 不可识别。已回流主智能体，将主按钮及面板标题按钮恢复 13px，原浏览器检查复测通过。详情见 `2026-09-27-mobile-button-repair.md` 和第二轮独立报告。

QA-02：培训管理手机页面被表单最小内容宽度撑至394px。调整网格列及表单控件收缩规则后，独立复测五页均为390px；实际打开培训表单后控件仍在视口内，截图复看通过。两项缺陷均已关闭，没有剩余已确认阻断问题。

历史未登记培训小时保持缺失，系统不会用日期跨度推算或编造既有数据。区域划分与人员归属由 HR 维护，不会凭岗位名称猜测批量分配。已有岗位名称变更按源表完成标记保留，本地合成测试不冒充生产岗位数据核验。
