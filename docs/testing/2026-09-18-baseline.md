## 启动和验收入口

按 README：`docker compose up -d postgres`，`bun install`，`bun run db:migrate`，配置临时种子密码后 `bun run db:seed`，分别运行 `bun run dev:server` 与 `bun run dev:web`。Web 为 localhost:3101，API 为 localhost:3000；`/api/health` 检查进程，`/api/ready` 检查数据库及迁移。

`bun run check` 包含静态检查、OpenAPI/部署合同、随机临时 PostgreSQL 数据库两次迁移及真实数据库行为合同、生产前端构建。可用专用 `POSTGRES_CONTRACT_ADMIN_URL`，不得指向生产库；脚本仍依赖 Docker daemon。`bun test` 为独立行为测试入口。
