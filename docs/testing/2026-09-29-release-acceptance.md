## 缺陷回流

1. 独立验收在真实HTTP复现负责人跨参训部门后看不到计划，开发新增真实数据库回归并修复读取条件，再由独立Chrome与数据库测试关闭。审批、撤回、取消及任务操作权限未扩大。
2. 跨部门负责人所见待审批计划人数曾依赖本部门员工列表，改为服务端全部有效对象去重计数，先红后绿验证。
3. 全站巡检发现装饰搜索、无响应通知按钮和示例工作台信息，改为真实入口与培训任务。独立验收进一步发现系统管理员没有业务通知权限，回传后隐藏其通知入口，保留服务端403保护并增加SSR回归。
4. 长名单挤压表格、手机导航标签与表单边界等问题由独立UI智能体整改，再交另一位智能体验证。
