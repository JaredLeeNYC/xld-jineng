## 已发现缺陷与复测闭环

1. **指定负责人待审批计划不可见**：真实 HTTP 红色复现后交回训练开发智能体；读取条件修复后原命令绿色，并独立完成真实 Chrome 桌面/手机验收。详见 `2026-09-29-approval-development.md` 及 visibility red/green JSON。
2. 浏览器验收脚本初轮存在旧 CSS 定位器、误认“新增资料”标题和未等待异步加载的断言问题。核对真实页面后修正脚本并完整重跑；这些属于验收脚本问题，不登记为产品缺陷。
3. **管理员通知按钮导向无权访问的业务通知**：最终真实 Chrome 在三种宽度发现；退回主开发智能体按角色隐藏按钮，保留服务端拒绝规则。独立复测管理员按钮不再出现、账号/审计入口可往返；员工通知继续正常。详见 `2026-09-29-final-ui-defects.md` 与 round1/final JSON。
