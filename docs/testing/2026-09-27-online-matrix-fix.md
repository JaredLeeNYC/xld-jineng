# 线上矩阵横向溢出修复

独立线上 HR 验收发现 ONLINE-UI-01：1440px 桌面展示多技能列时，文档宽度达到 2631px。父级 grid 默认自动最小宽度将表格内容宽度传播至整个页面。

修复在 `.matrix-page` 设置 `grid-template-columns: minmax(0, 1fr)`，并限制其自身与直接子项的最小宽度。表格继续保持内容宽度，由现有内部滚动容器承接。

本地使用真实 CSS 和 24 列矩阵复现：修复前页面 2537px、内部无法滚动；修复后页面 1440px、表格 2211px、内部可滚动 100px。`bun test` 168 项通过，598 条断言；`bun run check` 全部门禁通过，包括 PostgreSQL 认证/权限/培训审批合同与构建。

本记录证明修复与本地门禁通过。正式线上关闭该缺陷还需部署后的独立浏览器复验，记录在本地线上验收报告中。
