## 本轮合同覆盖

- 草稿提交审批、禁止自审批、另一 HR 审批自动发布、旧 publish 绕过拒绝。
- 撤回保留任务、修改后再次提交审批、复用未执行任务。
- 员工 submit 禁用、负责人开始/完成、实际时间、未开始不可完成、并发完成只写一份正式履历、正式记录不可篡改。
- 批量签到只处理已开始任务，培训材料/证据历史授权与停用边界。
- 评定直接待 HR、无附件保存、退回修改、独立归档、旧流程不能自审、归档重复并发与技能快照回滚。
- 部门/岗位编码更改、唯一冲突、无在岗岗位可换部门；有在岗岗位拒绝跨部门搬迁。
- 岗位要求删除鉴权、逻辑保留、矩阵排除、部门筛选。
- 全厂只读列表与档案，不扩大组织/培训写入范围。
- 多资料、多负责人、多部门 HTTP payload 往返、发布目标与每份资料访问 grant。
- 员工考核档案仅本人可见。
- 报表按第二份资料关联技能筛选，确认已完成培训计入分子与分母（均为 1）；HTTP 回归通过。
- 岗位多选发布与完整持久化，普通员工不能作为负责人。
- 基础数据停用保留行；按姓名唯一审核授权、缺失/重名拒绝、幂等及角色保持。
