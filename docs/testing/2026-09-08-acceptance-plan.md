# 独立验收计划（2026-09-08）

依据原始 Excel「问题」第 2—27 行、抽取 JSON 与第 18 行等级截图。由独立验收子智能体执行；开发自测不代替验收。正式执行须在开发宣布完成后开始，避免并发修改造成结果不可信。

## 验收口径

- 业务日期按中国标准时间，培训和评定按由近到远降序。评定原文同时出现“递增”，按明确的“由近到远”统一解释。
- 技能归档替代物理删除，历史引用、正式履历必须保留。
- 主管仅能操作授权范围；员工不能访问其他员工资料、管理动作或证据。
- 附件须实际展示内容，只有按钮、下载链接或“暂不支持”不算内容预览通过。PDF、PNG/JPEG/WEBP、DOC/DOCX、PPT/PPTX 按当前允许上传格式验证，培训资料、培训记录、评定证据三个入口均检查。
- 四个指定工号的生产角色变更需部署后的真实数据读回；本地模拟验证只能通过脚本行为项。

## 执行层次

1. 记录当前提交和工作区状态，检查迁移与现有数据兼容性。
2. 独立执行 `bun run check`（含真实 PostgreSQL 合同和前端生产构建）、`bun test`。保留日志与退出码；禁止以跳过数据库冒充门禁通过。
3. 对合同未覆盖的新要求补充独立行为验证。数据库使用独立测试数据；不连接生产执行业务写入。
4. 在真实浏览器以 HR001、MGR001、EMP001 验证上述页面，保存关键截图/状态证据；桌面表格、手机卡片和列表 loading/error/empty 状态。
5. 失败写入轮次报告，包含编号、严重度、Excel行、复现步骤、预期、实际、证据与返修要求。返回开发子智能体，开发完成后回归失败项和相关流程。
6. 所有可执行项通过才建议推送；生产账号与部署验收单独标记，不提前声称上线完成。
