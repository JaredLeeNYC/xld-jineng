# 一期上线验收清单

本清单用于单工厂云端部署。所有“实际结果”和证据链接必须由上线人员填写；模板中的待执行项不代表已通过。

## 初始化

- [ ] 使用至少 50 名真实或脱敏员工完成 Excel dry-run 与正式导入，重复工号为 0。
- [ ] 至少 3 个岗位已配置必备技能与要求等级。
- [ ] 五类角色各准备一个首次改密账号，临时密码通过安全渠道交付。

## 全链路

- [ ] HR 发布培训，员工收到站内通知并提交任务。
- [ ] 培训负责人/主管确认，系统生成正式培训履历。
- [ ] 评定人上传证据并提交，主管确认，HR 归档。
- [ ] 员工当前技能、岗位达标率、覆盖率和 Excel 同步更新。
- [ ] 到期扫描、退回、作废和失败评定均符合历史保留规则。

## 企业微信与通知

- [ ] 使用生产管理群 Webhook 执行测试发送，记录时间、渠道名称和接收截图；验收记录不得粘贴完整 URL 或 key。
- [ ] 使用受控失败渠道验证发送失败、尝试次数和人工重试。
- [ ] 核对培训、评定结果和到期站内通知。

## 发布与恢复

- [ ] 记录固定发布版本、审批人、操作者和发布时间。
- [ ] `bun test`、`bun run check`、数据库迁移 hash 和 Web 构建通过。
- [ ] 数据库 dump 与附件归档来自同一维护窗口，SHA-256 可读。
- [ ] 在隔离数据库和隔离附件目录完成恢复，登录并下载一份证据文件。
- [ ] 发布后 health、ready、OpenAPI、静态 Web、登录和会话自动读回通过。
- [ ] 回滚应用版本演练通过；数据库恢复仅在独立审批的维护窗口演练。
